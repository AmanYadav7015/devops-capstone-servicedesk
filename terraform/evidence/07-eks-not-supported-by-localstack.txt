What this proves and what it does not.

successfully, because LocalStack community does implement IAM and EC2. So the HCL in modules/eks
is sound and the failure is the emulator missing a service, not a defect in the configuration.
It is still only an HTTP 501 from an emulator. It is not a running EKS cluster and nothing here
claims that it is.
